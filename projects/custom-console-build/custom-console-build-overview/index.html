Custom Console Build - Overview

The idea

A retro-style game console built from scratch, inspired by early-2000s consoles: gathering around the TV, putting in a game disc, and playing locally with friends and family. The controller is built around motion sensing rather than pointing at the screen. The target game is a motion-controlled disc golf game for up to four players, stored on and launched from a physical disc.

Build philosophy

No off-the-shelf pre-built solutions. Each part of the system is designed and built by me, software included. The current prototype runs on ESP32 dev boards.

Controller, version 1

A button on top, a trigger button, a D-pad, and plus/minus buttons on the bottom. Motion sensing with an accelerometer and gyro. Power is either AA batteries or a lithium cell with a charge circuit (not decided yet).

Not in version 1

An IR pointer, rumble, and a speaker.

Target

Reliable enough to play a full nine-hole round of disc golf with four people.
