USB-C Connector Wiring

Wiring guide for the Hanbo MC-404L68-Z10 (8-pin, right-angle SMD) — confirmed pinout: GND, VBUS, CC1, DP1, DN1, CC2, VBUS, GND. USB charging input + native USB 2.0 to the ESP32-S3.

Pin Connections

Connector PinGoes ToPurpose
VBUS (both pins, tie together)MCP73831 VDD (charge IC input)USB power feeds the charge IC only — not the regulator/ESP32 directly. The board always runs off the battery via the TPS63031, whether or not USB is plugged in. MCP73831 charges the battery in parallel with whatever the device is drawing.
GND (both pins, tie together)Common ground
DP1 (D+)ESP32-S3-WROOM GPIO20 (native USB D+)Direct connection — ESP32-S3's native USB needs no external UART bridge chip
DN1 (D-)ESP32-S3-WROOM GPIO19 (native USB D-)Direct connection
CC15.1kΩ resistor to GNDRequired — signals to the USB-C host that this is a UFP (device) requesting default USB power. Without this, some hosts won't supply power at all.
CC25.1kΩ resistor to GNDSame as CC1 — both CC pins need their own independent pull-down, not shared.

Power Budget Note

Default USB power (no further negotiation beyond the CC pull-downs) is typically 500mA–900mA depending on the host/adapter. Charging at the planned 500mA (MCP73831, 2kΩ R_PROG) plus the device's own ~73mA draw while charging is close to but should fit within that default budget on most modern USB-C sources. No need for active power negotiation (no ESP32 GPIO connection to CC pins) since the fixed pull-down approach is sufficient here.

Recommended additions

  • ESD protection on D+/D-/VBUS — a small low-capacitance USB ESD diode array chip, placed right at the connector. Worth adding since this port gets plugged/unplugged repeatedly on a handheld device.
  • Local decoupling on VBUS — a small ceramic cap (1–10µF) right at the connector, separate from the big 470µF bulk cap elsewhere in the power path (that one serves the battery node, not USB input directly).

Part Notes

Hanbo MC-404L68-Z10, JLCPCB C47326498. 8-pin, right-angle SMD, 3A/5V rated, 10,000 mating cycles. Dual VBUS/GND pins tie together for better current handling — not separate nets. Pinout confirmed via JLCPCB's EasyEDA schematic symbol viewer, not assumed from the part name/description (a connector considered earlier, DEALON USB-TYPE-C-009, turned out to be power-only with no data pins despite looking similar on paper — worth always confirming the real pinout before committing).
