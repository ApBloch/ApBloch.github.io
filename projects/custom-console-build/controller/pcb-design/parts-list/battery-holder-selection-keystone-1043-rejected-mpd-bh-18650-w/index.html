Battery Holder Selection — Keystone 1043 (rejected) → MPD BH-18650-W

Decision write-up and mistake log. The first battery holder I ordered did not fit the battery this project uses. This note records why, what I changed, and how I verified the replacement before buying it.

Summary

  • Problem: The Keystone 1043 (a generic single-cell 18650 holder) did not fit the Panasonic NCR18650GA protected cell used in this build.
  • Cause: The protected version of the cell has a protection circuit built into its end, which makes it slightly longer than an unprotected 18650. "18650" describes the cell diameter and length class, but it does not guarantee that a holder fits a protected cell.
  • Fix: Switched to the MPD BH-18650-W, a holder that the manufacturer specifically designs for cells with built-in protection circuits.
  • Verification this time: Before ordering the replacement, I downloaded the manufacturer's 3D model and checked it against the physical battery in hand.
  • Cost of the mistake: One re-order (see "What it cost" below).
