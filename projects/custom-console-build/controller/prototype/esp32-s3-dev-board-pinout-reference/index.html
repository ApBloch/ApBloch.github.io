ESP32-S3 Dev Board Pinout Reference

Reference for the Hosyond ESP32-S3-WROOM-1 dev board (N16R8: 16MB flash, 8MB PSRAM). Pinout sourced directly from Espressif's official ESP32-S3-DevKitC-1 docs — this board is pinout-compatible with that reference design.

⚠ Reserved Pins — Do Not Use

Because this board has Octal SPI PSRAM (the R8 in N16R8), these pins are used internally for flash/PSRAM communication and are NOT available for your circuit:

  • GPIO35, GPIO36, GPIO37 — reserved, do not wire anything to these

Other Special-Purpose Pins

  • GPIO0 — Boot select pin (held low at reset = download mode). Usable as GPIO after boot, but avoid depending on its state during power-up.
  • GPIO45, GPIO46 — Strapping pins (affect boot behavior based on their state at reset). Usable but be careful with default states.
  • GPIO48 — Drives the onboard addressable RGB LED. Still usable as GPIO if you don't need the LED.
  • GPIO43 (TX) / GPIO44 (RX) — Default UART0, used for USB-to-UART programming/serial monitor. Avoid using for other purposes if you want to keep serial console access.
  • GPIO19, GPIO20 — USB D-/D+ (native USB OTG). Avoid if you want to keep the native USB port functional.

Good Pins for This Project

Suggested — not exhaustive. Cross off as you assign them in the Block Diagram.

  • SPI (for IMU): GPIO11 (MOSI/FSPID), GPIO13 (MISO/FSPIQ), GPIO12 (SCLK/FSPICLK), GPIO10 (CS/FSPICS0) — these are the hardware FSPI pins, good default choice for the IMU
  • I2C (alternative for IMU): any two free GPIO can be assigned via software (ESP32-S3 I2C is not pinned to fixed hardware pins) — e.g. GPIO8/GPIO9
  • Buttons/GPIO: GPIO4, 5, 6, 7, 15, 16, 17, 18, 3, 9, 14, 21, 1, 2, 42, 41, 40, 39, 38 — plenty of free general-purpose pins for A/B/D-pad/+-/Home
