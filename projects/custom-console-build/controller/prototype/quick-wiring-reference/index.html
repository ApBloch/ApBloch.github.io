Quick Wiring Reference

Bench reference for wiring the ESP32-S3 dev board to the LSM6DSV320X adapter (SPI). Full details in the two docs above.

Wiring — ESP32-S3 to IMU (SPI)

ESP32-S3 PinIMU Adapter Pin
3V3VDD, VDDIO
G (GND)GND
GPIO12 (SCLK)SCL
GPIO11 (MOSI)SDA
GPIO13 (MISO)SDO
GPIO10 (CS)CS
GPIO5 (interrupt in)INT1
GPIO6 (interrupt in)INT2

Decision: using interrupt-driven IMU reads (not polling) for the final design. GPIO5/GPIO6 are free general-purpose pins per the ESP32-S3 pinout reference — not yet wired/tested on the breadboard, but reserved for this in the pin plan.

Other Pin Assignments

  • GPIO4 — pushbutton (breadboard test)
  • GPIO7 (ADC1_CH6) — battery voltage sense (see Battery Voltage Sense doc)

Watch Out For

  • ESP32 GPIO35/36/37 are reserved — don't use for buttons or anything else
  • IMU's OCS/SCX/SDX/OSDO pins are a separate aux interface — leave unconnected
