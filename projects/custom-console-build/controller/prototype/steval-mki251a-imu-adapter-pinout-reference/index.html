STEVAL-MKI251A (IMU Adapter) Pinout Reference

Reference for the ST STEVAL-MKI251A adapter board a plain breakout that pins the bare LSM6DSV320X chip onto a standard DIL24 (24-pin DIP) socket. No onboard MCU, no voltage regulation beyond decoupling caps you supply VDD/VDDIO directly. Pinout confirmed from ST's official data brief (schematic + board photo).

Decoupling (already on board, no action needed)

  • 100nF between VDD and GND
  • 100nF between VDDIO and GND
  • 10uF between VDD and GND

Pins You'll Actually Use

DIL Pin #SignalFunction
1VDDMain supply voltage
2VDDIOI/O supply voltage (can be same as VDD, or lower for logic-level matching)
13GNDGround
14INT1Interrupt 1 (configurable \u2014 e.g. data-ready, motion detection)
15INT2Interrupt 2 (configurable)
19CSChip select. Tie HIGH for I2C mode. Use as SPI chip-select if wiring SPI.
20SCLI2C clock, or SPI SCLK
21SDAI2C data, or SPI MOSI
22SDOSPI MISO, or I2C address-select bit (ties to GND or VDDIO to set the I2C address)

Auxiliary/OIS Interface \u2014 Not Needed for This Project

These pins are a secondary SPI interface (OIS \u2014 optical image stabilization pass-through) for a different use case. Leave unconnected:

DIL Pin #Signal
3OCS (aux chip select)
4SCX (aux clock)
5SDX (aux data)
6OSDO (aux data out)

Wiring Notes

  • For I2C: connect VDD, VDDIO, GND, SCL, SDA. Tie CS to VDDIO (HIGH) to select I2C mode. SDO sets the I2C address bit tie to GND or VDDIO depending on which address you want.
  • For SPI: connect VDD, VDDIO, GND, SCL (SCLK), SDA (MOSI), SDO (MISO), CS (chip select, toggled by the ESP32).
  • INT1/INT2 are optional but useful can wire to ESP32 GPIO to get interrupt-driven reads instead of polling, worth considering once basic communication is confirmed working.
