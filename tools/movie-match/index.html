Movie Match

Connect to TMDB

Movie Match uses The Movie Database (TMDB) for its catalog, similar-movie suggestions, and streaming availability. It's free — you just need your own API key. Your key is stored only in this browser and never leaves your device (except in requests you make directly to TMDB).

How to get a free TMDB API key (about 2 minutes)
  1. Go to themoviedb.org/signup and create a free account (verify your email).
  2. Open your API settings (Profile → Settings → API).
  3. Click Create → choose Developer → accept the terms.
  4. Fill in the short form (for "Type of Use" pick Personal; you can put any URL like http://localhost and a brief description).
  5. Once approved (instant), copy the API Key (v3 auth) — a 32-character string.
  6. Paste it below.

Tip: use the API Key (v3 auth) value, not the longer "API Read Access Token".
